# hotelmap-data

Hotel Map アプリが読み込む「ホテルの期間限定イベント情報」のデータです。
GitHub Actions が毎日（JST 6:00）`tools/collect_events.py` を実行し、`events.json` を更新します。

## データの方針

- 出典：[PR TIMES](https://prtimes.jp/)（robots.txt で許可された範囲）
- 保存するのは **短いタイトル・期間（開始日・終了日）・種類・出典名・元ページの URL・取得日** のみ
- プレスリリースの本文や画像はコピーしません。詳しい内容は元のページをご覧ください
- アクセスは 1 秒に 1 回以下
- 終了日を過ぎた企画は載せません
- 期間は本文から機械的に読み取っているため、誤りがある場合があります。最新情報は各ホテルの公式発表をご確認ください

## ファイル

| ファイル | 内容 |
|---|---|
| `events.json` | 公開データ。`version`・`updated`（取得日時）・`events`（ホテル ID ごとの一覧） |
| `hotels.json` | 収集対象のホテル（ID・名前・英語名・都道府県） |
| `tools/collect_events.py` | 収集スクリプト（標準ライブラリのみ） |
